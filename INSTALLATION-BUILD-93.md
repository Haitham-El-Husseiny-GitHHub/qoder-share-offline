# Build 93

OpenCode new-chat heading removed. OpenCode uses the Android document picker for arbitrary files; imports stay with each conversation draft and are included as validated absolute workspace paths when sending. APKs, archives, documents, images and user-selected configuration files are accepted, with eight files per message and 256 MB per file. Processing depends on the selected model and available inspection tools.

Qoder keeps its original Sessions interface. Tap the connection/credits strip for API key and Attach files. For attachments, focus the message field first, choose files, and use Add to message to place imported paths in the draft.

Qoder personal access tokens are stored in a private mode-600 runtime file and supplied to CLI launches and localhost restarts. OpenCode credentials use its persistent native auth store. Neither has an application timeout; replacement/removal is explicit. Provider revocation/expiry still applies. The Qoder credit counter reads the existing browser account only when no PAT override is saved; PAT users see an account usage message instead of another account's quota.
